I am learning Git and GitHub.

Git is a version control system used to track changes in files.

GitHub is an online platform used to store and share code.

Git Commands:
1. git init - Initialize a Git repository.
2. git add . - Add files to the staging area.
3. git commit -m "First commit" - Save changes.
4. git status - Check the status of files.
5. git push - Upload changes to GitHub.
6. git pull - Get the latest changes from GitHub.

Git has three main local areas:
1. Working Directory
2. Staging Area
3. Local Repository

A remote repository, such as GitHub, allows us to share our project online.
